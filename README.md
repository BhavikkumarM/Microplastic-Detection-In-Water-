# Microplastic-Detection-In-Water-
This project delivers an end-to-end, real-time Computer Vision system for **Microplastic Detection and Polymer Classification** utilizing state-of-the-art Deep Learning object detection models. 

Microplastics (synthetic polymer particles $< 5\text{ mm}$ in diameter) represent an escalating global ecological crisis. Traditional laboratory identification methods—such as Fourier Transform Infrared Spectroscopy (FTIR) and Raman Spectroscopy—are accurate but remain destructively slow, expensive, manual, and unsuitable for continuous environmental monitoring or automated waste sorting.

This project addresses these limitations by training and benchmarking three generations of lightweight **You Only Look Once (YOLO)** architectures:
1. **YOLOv8n** (Ultralytics v8 Nano)
2. **YOLO11n** (Ultralytics v11 Nano - State of the Art)
3. **YOLO26n** (Customized Lightweight Architecture Variant)
